# Модуль управления товарами и категориями main.py

Данный модуль реализует базовую объектно-ориентированную модель
для работы с товарами и их категориями.
Он включает два основных класса: Product и Category.

Класс Category описывает категорию товаров и управляет группой объектов Product.

# Содержит:
name — название категории
description — описание категории
products — список товаров (объекты Product)

# Статистика:
Класс Category также ведёт общий учёт:

category_count — общее количество созданных категорий
product_count — общее количество товаров во всех категориях

При создании каждой новой категории:

счётчик категорий увеличивается на 1
счётчик товаров увеличивается на количество товаров в категории
